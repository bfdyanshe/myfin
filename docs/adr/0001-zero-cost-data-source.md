# ADR-0001：坚持零成本数据方案

- 状态：已接受（v1）
- 日期：2026-08
- 相关：`docs/data-sources.md`、`config/sources.toml`、`docs/strategy.md` §3.1

## 背景

myfin 是个人研究项目，数据预算为零。候选数据源中 Tushare 是覆盖面最广的商业源，
但其付费档位与免费档位差距显著；乐咕（legulegu）的历史 PE/PB 分位接口已停更；
AKShare 免费但依赖爬虫接口，稳定性差。

关键事实（已核实）：

1. Tushare **免费档（120 积分）仅可用不复权日线 `daily` 与交易日历**；
   `daily_basic`（每日估值指标）、财务数据、复权数据均需 **2000 积分**（约 200 元/年）。
2. 乐咕 PE/PB 历史分位接口停更，外部现成的「历史分位」数据不可得。
3. Baostock（免费、零注册、匿名登录）提供 2007 年以来的季频财务、业绩预告/快报、复权因子。

## 决策

**坚持零成本数据方案**：

- 估值指标（PE/PB）及历史分位全部**本地自算**：
  市值 = 不复权收盘价 × 总股本；PE = 市值 / TTM 归母净利；PB = 市值 / 归母股东权益
  （口径见 `docs/strategy.md` §3.1，代码模型见 `crates/mf-core/src/valuation.rs`）。
- 财务、预告/快报、复权因子主源：Baostock；行情主源：mootdx，备源腾讯财经，兜底 Tushare 免费档。
- 不购买任何积分/数据服务，注册表内不出现付费源（`config/sources.toml`）。

## 备选方案对比

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| Tushare 2000 积分（约 200 元/年） | 直接拿到 `daily_basic`、财务、复权，字段全 | 每年付费；积分与数据权限绑定，服务曾宕机 | 否决：预算为零，且自算口径完全够用 |
| 乐咕历史分位 | 现成分位 | **已停更**，不可用 | 否决：数据源不存在 |
| 本地自算（本决策） | 零成本；口径完全可控；as-of 纪律下与回测一致 | 公告日需近似（+60 天）；股本数据需从行情源取（`PriceVal.total_shares`） | 接受 |

## 后果

- **收益**：零成本；PE/PB 分位口径透明、可复现；不依赖任何商业 API 的可用性；
  自算路径天然满足 as-of 纪律（分位只依赖报告期财务与当日行情，无第三方快照的前视风险）。
- **成本**：公告日近似（报告期末 + 60 天）引入 as-of 精度损失，须在报告数据质量页声明；
  股本变化（增发/回购注销）依赖 `PriceVal` 的及时性，偶发股本更新滞后会影响估值；
  损失了 `daily_basic` 的市盈率/市净率/换手等便捷字段，部分因子需自行实现或放弃。
- 此决策通过 `docs/adr/0002`（不复权存储）与 `docs/adr/0003`（回测先行）固化配套约束。
