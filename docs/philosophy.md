# myfin 投资理念

> 状态：v1 · 相关文档：`docs/strategy.md`（可执行规格）、`docs/architecture.md`（实现结构）、
> `docs/data-sources.md`（数据可得性）、`docs/adr/`（三条决策记录）。
> 本文说明「为什么这样做」，`docs/strategy.md` 说明「具体怎么做」。

## 一句话定义

myfin 是一个个人量化选股系统：在**当前时点**选出「**当前低估、但基本面正在回升**」的 A 股标的，
持有 **6 个月**，**不做市场择时**。

三个限定词都是刻意选择：

- **当前低估**：便宜是买入的必要条件，但不是充分条件——便宜的东西可能越来越便宜。
- **正在回升**：基本面拐点（业绩预告/快报转正等）出现，市场开始重新定价。
- **6 个月持有**：给「低估值修复 + 业绩兑现」一个明确的期限，到期无论盈亏退出。

## 核心命题

> 在估值历史分位底部区域买入「基本面已出现向上拐点」的标的，持有 6 个月，
> 赚取估值修复 + 业绩改善两重收益；用明确期限约束持有，不做趋势追随。

这一命题建立在两条经验公理上，且两条公理都**可以回测证伪**（见 `docs/adr/0003`）：

1. **均值回归**：A 股估值存在显著的历史均值回归倾向——估值分位极低（5 年分位 < 30%）
   的标的，未来 6 个月估值扩张的概率高于收缩；本策略只对「低分位」下注，对「更低分位」不对赌。
2. **业绩拐点先行**：业绩预告/快报披露远早于正式财报，净利同比由负转正（主信号）是
   基本面修复最早的机器可读证据，其披露后的 6 个月通常是预期修正最集中的窗口。

本策略与两类常见策略刻意区分：

| 对比对象 | 差异 |
| --- | --- |
| 价值投资（深度价值） | 我们同样要求便宜，但**要求回升信号确认**，不接「跌无可跌」的落刀 |
| 动量/趋势策略 | 我们同样要求动量为正，但**起点必须是低估值**，不在高位追涨 |
| 行业轮动/择时 | 我们不做自上而下仓位调整，环境信息只用于**归因标签**而非决策开关 |

## 环境性低估 vs 资产性不良

策略的全部选股工作可以归结为一件事：**分辨一个便宜的公司，是「被环境错杀」还是「本身就是不良资产」**。

- **环境性低估**：公司基本面（营收、利润、现金流）健康或处于周期底部，估值低的原因是外部环境——
  宏观经济周期、行业政策、地缘事件、产业周期下行——压制了整个板块的定价。
  这类低估具备**修复机制**：环境一旦好转或不再恶化，估值会均值回归。
- **资产性不良**：公司自身造血能力丧失——收入萎缩、持续亏损、现金流恶化、负债失控。
  环境不构成主要解释，便宜是基本面恶化的正确定价。这类标的的「低估」是价值陷阱。

同一家公司可能同时有环境与自身因素，框架的目的不是二分，而是**归因**：
环境标签（如「行业景气触底」「政策压制」）进入输出的 `env_tags`，
财务健康度决定是否进入不良排除或风险旗标。

两种情形的证据链示意：

| 观察 | 指向环境性低估 | 指向资产性不良 |
| --- | --- | --- |
| 行业整体 | 行业多数公司同步被压、行业指数跌透 | 仅个别公司恶化、行业其他公司正常 |
| 财务趋势 | 下滑幅度与行业同步，现金流尚为正 | 营收/利润加速恶化，经营现金流持续为负 |
| 事件 | 明确的一次性冲击（政策/地缘） | 无外部解释，或解释是长期结构性的 |
| 负债 | 负债率正常 | 负债率 > 70% 且持续攀升 |
| 资金面 | 量能萎缩但开始放量 | 缩量阴跌无承接 |

### 分辨检查清单

对一个候选标的，按下述四个维度逐项核对（数据来源见 `docs/data-sources.md`；
可机器化的部分已落入 `config/screen.toml` 参数，人工核对的输出进 `data/context/`）：

1. **行业景气位置**
   - 行业处于周期什么位置？需求端是趋势性萎缩还是周期性回落？
   - 行业相对收益：过去 6–12 个月行业指数相对全市场是否已经跌透（策略以数据化标签记录）？
   - 若行业景气已确认触底回升，公司低估值更可能是环境性的；若行业仍在趋势性下滑，需更高证据强度。

2. **政策 / 地缘影响**
   - 公司或行业近期是否受政策（监管、补贴退坡、行业整顿）或地缘事件直接冲击？
   - 冲击是一次性的（事件过去即修复）还是持续性的（商业模式受损）？
   - 政策数据来源有限：以 AKShare 宏观/新闻辅助 + 人工核查为主，不机器化决策。

3. **财务健康**
   - 营收/利润趋势：连续几个报告期下滑？TTM 净利是否为正？（对应 `exclusion` 配置）
   - 经营现金流：经营现金流是否持续为负？利润是否只是账面利润？（`max_neg_cashflow_quarters`）
   - 负债结构：资产负债率是否过高？（`max_debt_ratio`）
   - 净资产是否为正（资不抵债直接出池）；审计意见类型——**注意：免费数据源无审计意见字段，
     该项只能人工复核**（见 `docs/strategy.md` 已知精度限制）。

4. **资金面**
   - 成交是否活跃（流动性下限 `min_avg_amount`），近期量能是否开始回升（`volume_ratio_min`）？
   - 是否存在与基本面无关的资金面事件（解禁、质押、减持、监管处罚）？
   - 北向资金日频数据自 2024-08-19 起停止披露，**不得作为信号**。

四个维度的结论不取加权打分，而是**证据链判定**：行业与政策维度解释「为什么便宜」，
财务维度排除「便宜是因为烂」，资金面维度确认「有人开始重新定价」。
任一维度出现「资产性不良」方向的强证据（资不抵债、现金流持续为负、负债失控），
直接按不良排除处理，不与环境证据对冲。

## 理念如何落到流水线

六阶段流水线（`docs/strategy.md`）与理念的对应关系：

| 流水线阶段 | 理念落点 |
| --- | --- |
| ① universe | 定义「可投对象」的边界：剔除退市风险、流动性不足 |
| ② environment | 环境归因：数据化标签回答「为什么便宜」，区分环境 vs 资产问题 |
| ③ undervalued | 「当前低估」的量化定义：PE/PB 5 年双分位 < 30% |
| ④ exclude_bad | 不良资产排除：连续亏损、现金流为负、高负债、资不抵债 |
| ⑤ recovery | 「正在回升」的确认：业绩拐点（主）→ 分位回升 → 动量/均线 → 量能 |
| ⑥ output | 归因标签 + 风险旗标 + 数据质量页，供人复核 |

## 不做择时的含义

「不做择时」在本策略中有精确含义，且分两个层面：

1. **不做宏观择时**：不因宏观判断（经济数据、政策预期、市场情绪）改变仓位或入场时点。
   环境扫描阶段产出的行业标签只用于**归因与排序**（放进 `env_tags`），不充当买入/卖出的开关。
   系统永远在「便宜 + 回升」的标的出现时选股，而不是在市场便宜时选股。

2. **个股级右侧确认是策略必需，不构成择时**：回升确认（业绩拐点、分位回升、动量、均线、量能）
   是**选股条件**而非择时动作。买入一家便宜但仍在下跌的公司，相当于对「它会涨」下注；
   本策略拒绝这种下注，要求看到基本面或价格的向上证据后才介入。
   这不是择时，是「被低估 ≠ 可以买」的纪律。

## 为什么持有期 6 个月

- 业绩预告/快报披露后的基本面修复，通常在 1–2 个报告期（6 个月左右）内被市场定价；
- 6 个月时间止损约束「便宜了还会更便宜」的风险，避免价值陷阱无限期持有；
- 明确的期限使回测和实盘的行为一致（见 `docs/adr/0003-backtest-first-validation.md`）。

## 策略不适用的场景

- **高位追涨**：估值分位已高（> 30%）的标的无论动能多强，都不是本策略对象；
- **深度价值陷阱**：财务不良（阶段④排除项）的标的，即使分位更低也不介入；
- **极端事件驱动**：突发黑天鹅（停牌、财务造假立案、退市风险）不在模型内，以退出规则处理；
- **风格极端分化期**：成长风格长期占优时，低估值策略可能长时间跑输（逆风格风险）。

## 风险声明

- 本项目是**个人研究用途**，不构成任何投资建议；作者不对任何依据本项目做出的投资决策负责。
- 数据全部来自免费公开数据源，存在延迟、缺失与口径不一致（见 `docs/data-sources.md`），
  回测结果仅代表历史区间内该规则的统计表现，不保证未来收益。
- 主要固有风险：
  - **逆风格风险**：策略本质是「低估值 + 反转」，长期跑赢的风格不是它（如成长/景气），
    在风格极端分化时期可能长时间跑输；
  - **价值陷阱风险**：低估筛选无法完全排除不良资产，财报证伪时需要按退出规则止损；
  - **数据质量风险**：公告日近似（报告期末 + 60 天）会造成 as-of 精度损失，
    免费行情源存在断档与字段缺失；
  - **极端尾部风险**：退市、面值跌破 1 元、长期停牌等在历史回测中可能未被充分覆盖。
